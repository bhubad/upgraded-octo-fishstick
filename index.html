OSRIC Character Sheet

An Owlbear Rodeo extension that shows an editable character sheet for any character token, laid out like the 1st Edition / OSRIC Automated Charactersheet by FlacoAlto, without its formulas or dropdowns.

Add it to Owlbear Rodeo

  1. In your Owlbear Rodeo profile, click Add Extension and paste this install link:
  1. Turn it on for a room: select it when you create a new room, or open an existing room and add it from the extension menu.
  2. In the room, right-click a character token → OSRIC Character Sheet. The extension's button at the top left lists every sheet in the scene.
